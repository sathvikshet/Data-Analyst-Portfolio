## 🤖 MACHINE LEARNING PROJECTS

### 1️⃣ Customer Churn Prediction System
**Focus:** Predict customer churn and identify high-risk customers for retention strategies.

Built a machine learning model to predict whether telecom customers will churn. The project includes data cleaning, exploratory data analysis, feature engineering, model training, evaluation, and deployment using Streamlit.

**Models Used:**
- Logistic Regression — Accuracy: 0.81
- Random Forest — Accuracy: 0.80

**Key Insights:**
- Customers with month-to-month contracts churn more
- Customers with low tenure are more likely to churn
- Higher monthly charges increase churn risk

**Business Impact:**
- Helps identify high-risk customers
- Supports retention strategies and targeted discounts
- Improves customer retention planning

📂 Folder: `machine-learning-projects/customer-churn-prediction`

---

### 2️⃣ Retail Sales Forecasting Using Machine Learning
**Focus:** Forecast future retail sales using time-series feature engineering and machine learning.

Built a sales forecasting system using lag features and rolling mean features. Compared multiple models and selected the best model for forecasting. Predictions are deployed using a Streamlit dashboard.

**Models Used:**
- Linear Regression
- Gradient Boosting
- Random Forest (Best Model, R² = 0.81)

**Key Insights:**
- Promotions significantly increase sales
- Holiday weeks have higher sales
- Previous week sales strongly influence future sales
- Fuel price and CPI impact sales trends

**Business Impact:**
- Helps inventory planning
- Helps promotion planning
- Supports sales forecasting and budgeting

📂 Folder: `machine-learning-projects/retail-sales-forecasting`
